This repository contains the code and the results from multiple different runs for both the black hole raytracer (Python) and the fluid solver (C++).
This is built as a month-long computational project from May-Jun 2026, although commits and early work has been done before the official start of the summer project. This is NOT built as production code.

Refer to the write-up (writeup.pdf) for the details of the teamwork.
Refer to src/render/Images for test runs with the renderer and the final 120-frame video (video.mp4) that illustrates an orbit around a Schwarzschild black hole.
